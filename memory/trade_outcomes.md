# Trade Outcomes Memory

Persistent log of every closed trade + Gate 4 reasoning that approved it.
Read by the LLM gate before each new decision on the same ticker.
Appended by PositionManager when a trade closes (WIN/LOSS/EOD).

Format per raw entry:
  ## TICKER | OUTCOME | YYYY-MM-DD
  - Session, entry/exit price
  - P&L (USD and %)
  - Gate reasoning (120 chars from trading_decisions.log)

Format per pattern note (auto-generated by compaction):
  ## [PATTERN] TICKER
  - Win rate, session breakdown, avg P&L
  - Updated each compaction cycle (every 50 raw entries)
